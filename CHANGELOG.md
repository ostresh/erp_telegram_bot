# Changelog

Все заметные изменения проекта. Формат основан на
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии следуют [Semantic Versioning](https://semver.org/lang/ru/).

## v2.0.0 - 2026-10-26

### Added
- Каталог игр: добавление, изменение и удаление записей.
- Отчёты по движению товаров, продажам и полный финансовый отчёт.
- Фоновая выгрузка отчётов в Excel через Celery с отправкой файла в чат.
- Оптовые заказы: создание, добавление доставки, отметка прибытия,
  просмотр активных и всех заказов, удаление.
- Дополнительные действия по товарам: обмен, бронь, комментарий,
  склад и доставка («в пути ко мне» / «в пути к клиенту»).
- Диалоги описания объявления и финансовый DTO.
- Автоочистка сервисных сообщений бота планировщиком Celery beat.
- Docker Compose для локального запуска и продакшена, `.env.example`.
- Документация по инфраструктуре, разработке и эксплуатации сервера.

### Changed
- Динамическое меню: дерево меню в коде, хлебные крошки, навигация inline-кнопками.
- Репозитории разделены: отчётные запросы вынесены в `FinanceReportRepository`
  и `SalesReportRepository`.
- Унифицированы методы поиска и получения записей в `GameRepository`,
  `RecordRepository` и соответствующих сервисах.
- Переработана структура `docker-compose` для локального и прод-окружений.
- Обновлена версия проекта до 2.0.0.

### Fixed
- Исправлена работа диалога отчёта по движению товара.
- Исправлена задача Celery и формат даты.
- Очищены базовые слои и сервис меню, удалён `__pycache__` из отслеживания.
