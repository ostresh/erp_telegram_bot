# Политика аутентификации API

- Секреты только в переменных окружения / secret store.
- Dev: допустим сырой API_TOKEN в .env (файл не в Git).
- Prod: только API_TOKEN_SHA256 (hex, 64 символа). Сырой токен запрещён.
- Одновременно два секрета задавать нельзя.
- Конфигурация валидируется на старте (fail-closed).
- Минимальная длина токена: 32 символа.
- Максимальная длина входящего токена: 256 символов (настраивается).
- Все ошибки аутентификации: одинаковый 401 + WWW-Authenticate: Bearer.
- Токены в логах запрещены. Допустим только key_id/fingerprint.
